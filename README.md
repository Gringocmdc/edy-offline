# EDY Offline v2.0.0

Actualización acumulativa del Centro de Supervivencia Digital Familiar.

## Puede instalarse directamente
No es necesario publicar primero las versiones 1.6.0, 1.6.1 o 1.6.2. Este paquete contiene todas sus funciones y las migraciones necesarias desde versiones 1.5.x y 1.6.x.

## Novedades 2.0
- Separa **100 L de agua potable** del sistema fijo de agua de la propiedad.
- Registra capacidad de cisterna, tanques, pozo, tipo de bombeo y respaldo eléctrico.
- Distingue capacidad instalada, volumen actual y parte reservada para la familia.
- Nuevo **Perfil privado del hogar**; la dirección exacta no se incluye en el repositorio público.
- Nuevo **Perfil de riesgos** con prioridades, acciones preventivas y cobertura automática según inventario.
- Dashboard inteligente con agua potable, agua fija, pozo, riesgos y prioridades abiertas.
- Protocolos para anegamiento, incendio y calor extremo.
- Respaldo 2.0 incluye hogar, agua y riesgos.
- Inventario acumulativo con 12 BIC Maxi J6, contactos, mochilas 72 h, botiquín Lisfar, Forza FPP-T702 y kit solar SPICA SUR-60.

## Archivos privados
El ZIP público **no contiene la dirección ni teléfonos familiares**. Importar por separado el archivo `EDY-perfil-privado-Familia-DellEra-v2.0.json`. No subir ese JSON a GitHub.

## Publicación
1. Exportar respaldo desde la versión actual.
2. Subir el contenido de este ZIP a la raíz del repositorio.
3. Abrir `actualizar.html` una sola vez.
4. Entrar en **Mi hogar** e importar el archivo privado.
5. Registrar los niveles actuales de cisterna y tanques; las capacidades no se toman como volumen disponible.
