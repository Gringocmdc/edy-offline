## Puede instalarse directamente
No es necesario publicar versiones intermedias. El paquete conserva todas las funciones anteriores y agrega automáticamente al inventario los nuevos elementos sin borrar cantidades ni cambios locales.

## Seguridad del generador
El generador debe funcionar únicamente al aire libre y lejos de puertas, ventanas y entradas de aire. Nunca debe utilizarse dentro del depósito ni conectarse a un tomacorriente para retroalimentar la instalación. Una transferencia fija debe ser instalada por un electricista.

## Privacidad
El ZIP público no contiene dirección exacta, teléfonos familiares, números de serie ni ubicaciones privadas. Esos datos se completan localmente o se importan desde el perfil privado separado. Las fotografías incluidas fueron convertidas a WebP y no conservan metadatos EXIF.

## Publicación en GitHub
1. Exportar un respaldo desde la versión actual.
2. Subir el contenido de este ZIP a la raíz del repositorio.
3. Abrir `actualizar.html` una sola vez.
4. Volver a entrar a EDY y abrir **Centro de Energía**.
5. Registrar combustible, consumo real y fecha de la última prueba.
